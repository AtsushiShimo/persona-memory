# Scenario 02: 長期ペット飼育 (skeleton)

## 設定

数週間〜数ヶ月にわたる継続会話で, ペットの体重 / 食事 / 通院記録 / 性格 等
の **個別事実が積み上がっていく** タイプの記憶テスト. session_id を複数に
切って /clear 後の cross-session recall も測定する.

## 埋め込み予定の事実 (todo)

- ペットの種別 / 名前 / 生年月日
- 体重推移 (4 回測定値)
- 食事の好み / アレルギー
- 通院歴 (2 回, 別 session)
- 性格メモ (慎重 / 人見知り 等)

## probe 候補 (3 件, 残り 27 件は後日)

- p01: "体重前回いくつだった?" (= 直近測定値 recall)
- p02: "アレルギーあったよね、 何だっけ?" (= 過去 session 跨ぎ)
- p03: "性格こういう感じだったよね?" (= 暗黙参照)
