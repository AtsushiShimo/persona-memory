# Scenario 01: Renju ゲーム開発

## 設定

ユーザーが約 50 turn かけて五目並べ系ゲーム (内部呼称 "Gomoku-Five") を
ペアプロ assistant と設計していく会話. test3 で実際に行われた議論を
参考に, 以下の **記憶が問われる構造** を意図的に埋め込む.

## 雑談 noise turn

recall の selectivity を測るため、 以下を散布:

- コーヒー談義 (turn 22, 32, 44)
- 天気の話 (turn 18, 41)
- 別件 (= ペット 件) を 1 turn 軽く触れる (turn 35)

これらが probe で誤想起されないこと, かつ Renju 関連 probe に noise が
混ざらないことを確認する.
